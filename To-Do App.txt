Samenvatting Backend Endpoints voor HTTPie

Users (/users):
POST   /users                      - aanmaken
GET    /users                      - alle users
GET    /users/{id}                 - user op id
PUT    /users/{id}                 - update
DELETE /users/{id}                 - verwijderen
PUT    /users/change-password      - wachtwoord wijzigen

TaskList (/tasklist):
POST   /tasklist                   - aanmaken
GET    /tasklist                   - alle tasklists
GET    /tasklist/{id}              - specifieke tasklist
GET    /tasklist/user/{userId}     - tasklists van user
PUT    /tasklist/{id}              - update
DELETE /tasklist/{id}              - verwijderen

Task (/task):
POST   /task                       - aanmaken
GET    /task                       - alle tasks
GET    /task/{id}                  - specifieke task
GET    /task/tasklist/{taskListId} - tasks van tasklist
PUT    /task/{id}                  - update
DELETE /task/{id}                  - verwijderen
PATCH  /task/{id}/status           - status wijzigen
POST   /task/{id}/migrate          - taak migreren (target: TOMORROW | NEXT_MONDAY | NEXT_MONTH_START | NEXT_JANUARY_FIRST)

Status enum:
CREATED, IN_PROGRESS, DONE, TESTING, ARCHIVED, MIGRATED

MigrationTarget enum:
TOMORROW, NEXT_MONDAY, NEXT_MONTH_START, NEXT_JANUARY_FIRST
